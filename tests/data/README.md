# Test and example data

All files contain two columns: voltage (V) and current (mA). Device area 0.09 cm² unless stated.

## Measured curves

Measured organic solar cells (Universidade Federal do Paraná). These are the curves shown in the
screenshots of JV Analysis Hub in Figs. 12–15 of the paper
(K. Rosivan Maia Pacheco et al., *Comput. Phys. Commun.* **324** (2026) 110129), so the figures can be
reproduced with jvhub.

| File | Curve | Figure | Analysis |
|---|---|---|---|
| `illuminated_real.txt` | illuminated | Fig. 12 | `pv_parameters` |
| `dark_mott_gurney_real.csv` | dark | Fig. 13 | `mott_gurney` (thickness 100 nm, ε<sub>r</sub> = 3.9 in the paper) |
| `dark_circuital_real.txt` | dark | Fig. 14 | `circuital_model` |
| `dark_richardson_schottky_real.csv` | dark | Fig. 15 | `richardson_schottky` (thickness 350 nm) |

## Synthetic curves

Generated by `make_synthetic.py` (fixed random seed; run `python tests/data/make_synthetic.py` to
recreate them) with realistic noise:

| File | Model |
|---|---|
| `illuminated_synthetic_1.txt` | one-diode cell, area 0.066 cm²: I<sub>ph</sub> = 1.21 mA, I<sub>0</sub> = 2×10⁻¹⁰ A, n = 1.8, R<sub>s</sub> = 12 Ω, R<sub>sh</sub> = 6 kΩ |
| `illuminated_synthetic_2.txt` | one-diode cell: I<sub>ph</sub> = 1.92 mA, I<sub>0</sub> = 5×10⁻¹³ A, n = 1.6, R<sub>s</sub> = 10 Ω, R<sub>sh</sub> = 20 kΩ |
| `dark_synthetic.csv` | diode + shunt in series with a space-charge-limited bulk: R<sub>sh</sub> = 80 Ω, J<sub>0</sub> = 10⁻¹⁴ A/m², μ = 5.5×10⁻⁸ m²/(V s), L = 105 nm |
| `dark_synthetic_tab_header.txt` | same model, tab separated with a header line: R<sub>sh</sub> = 70 Ω, J<sub>0</sub> = 3×10⁻¹⁴ A/m², μ = 6×10⁻⁸ m²/(V s) |
